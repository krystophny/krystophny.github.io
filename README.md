# krystophny.github.io

Personal website. Plain HTML: no site generator, no CSS framework, no web
fonts. `make`, `sh` and `sed` do the whole build, and the only JavaScript is
the search and filter on the publications page.

## Build

```sh
make          # build into public/
make serve    # build and serve on :8000
```

GitHub Pages publishes `public/` from `.github/workflows/pages.yml`, so
nothing generated is committed. The workflow installs nothing: `make`, `sh`
and `sed` are already on the runner.

## Layout

- `pages/`: one HTML body fragment per page. No front matter. The page title
  is the text of its first `<h1>`.
- `parts/head.html`, `parts/foot.html`: the shared header, nav and footer.
- `static/`: copied verbatim to the site root.
- `build.sh`: assembles one page, expanding `{{TITLE}}`, `{{BASE}}` and the
  cache-buster `{{V}}`.

`pages/research.html` becomes `public/research/index.html`, so the URL stays
`/research/`. `pages/404.html` becomes `public/404.html`, which is what
GitHub Pages serves for a missing page.

## Adding a page

Write `pages/whatever.html` starting with an `<h1>`, then add it to the nav in
`parts/head.html`.

## Publication list

`static/css/publications.css`, `static/js/publications.js` and
`static/data/publications.json` are generated by the private
`krystophny/publication-registry` repo and copied here by its
`make publish-local`. Do not edit them here.

## Styling

`static/css/site.css` is the whole stylesheet, shared with the group site. It
sets no font and no colours: `color-scheme: light dark` makes the browser
paint its own light and dark canvas, text and link colours.
