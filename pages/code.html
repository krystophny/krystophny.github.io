Code

I'm the maintainer of the following open source codes:

  • SIMPLE: symplectic integrators for guiding-center motion in electromagnetic fields
  • NEO-RT: computes ion neoclassical toroidal viscous torque in tokamak plasmas including finite orbit width
  • proFit: Python toolkit for response surface model fitting with uncertainty quantification
  • fffi: Fortran foreign function interface for Python, part of pyccel
  • TpX: GUI drawing tool for LaTeX/TikZ figures
